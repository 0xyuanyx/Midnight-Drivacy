가입자 인증 → 임베디드 월렛 연결

이메일 인증, 신규 가입자의 기본 정보 입력, 기기 월렛 연결 순서를 검토하는 와이어프레임입니다. 흰 카드와 파란 주요 버튼은 제공한 앱 디자인의 기준만 반영했습니다.

레퍼런스 전용 · 입력값 전송 없음 · 실제 계정/월렛 생성 없음
공통 이메일 입력 → 6자리 코드 확인 → 첫 이용 이름·생년월일·전화번호 입력 → 월렛 안내 → 생성 → 연결 확인
재방문 같은 이메일 화면 → 코드 확인 → 기존 월렛 잠금 해제 → 연결 확인
예외 연결 실패 시 같은 월렛으로 재시도 · 다른 기기에서 월렛이 없으면 복구 안내

화면 연결 규칙　코드 확인 뒤 프로필이 없거나 미완료이면 기본 정보를 입력하고, 완료돼 있으면 기존 월렛 상태를 확인합니다. 이름·생년월일·전화번호는 입력 정보이며 인증하지 않습니다. 이 정보만으로 실제 보험계약을 조회하거나 연결하지 않습니다. 이메일 인증으로 월렛 키가 복구되지는 않으며, SDK 연결 성공 전에는 완료 화면으로 보내지 않습니다.
