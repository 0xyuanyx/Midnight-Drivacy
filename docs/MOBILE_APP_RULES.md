# Drivacy 앱 디자인·동작 규칙

확정: 2026-09-22. 범위: `apps/mobile`의 React Native 가입자 앱과 웹 미리보기.

## 판단 우선순위

1. 최신 사용자 결정과 앱에서 합의한 개선사항
2. 이 문서와 실제 공통 컴포넌트·토큰
3. 최신 Figma의 시각적 구성과 원본 자산

Figma의 화면별 좌표가 달라도 합의한 eyebrow·CTA 정렬과 떠 있는 탭바를 되돌리지 않는다. 잘림·겹침·역할별 불일치는 공통 규칙으로 개선한다. 새로운 화면 흐름, 데이터 의미, 브랜드 변경은 근거와 제안을 먼저 알린다. 디자인 취향만으로 범위를 넓히지 않는다.

## 글자 역할

실제 번들된 Pretendard Regular/SemiBold/Bold를 사용한다. `src/theme/typography.ts`가 실행 기준이다. 숫자는 고정폭 숫자를 사용한다. 글자 확대를 막거나 내용에 맞춰 글자를 임의 축소하지 않는다.

| 역할 | 크기/줄높이 | 굵기 |
|---|---|---|
| 시작 화면 제목 | 30/40 | Bold |
| 일반 화면 제목 | 24/34 | Bold |
| 동의 시트 제목 | 22/32 | Bold |
| 카드·내비게이션 제목 | 16/24 | SemiBold |
| 화면 설명·동의 본문 | 16/25 | Regular |
| 보조 설명·데이터 라벨 | 13/20 | Regular |
| 데이터 값·짧은 강조 | 13/20 | SemiBold |
| 상태 배지 | 11/16 | SemiBold |
| CTA | 16/24 | SemiBold |
| eyebrow | 11/16 | SemiBold |
| 탭 라벨 | 10/14 | SemiBold |
| 주요 숫자 | 40/50 | Bold |
| 보조 숫자·주행 타이머 | 24/32 | Bold |

위 값은 이번 앱 정리에서 채택한 규격이다. Figma 전체에서 추출한 값이라고 주장하지 않는다. Figma에서 직접 확인한 Body Medium 16/25를 본문 기준으로 삼고, 기존 9~11px 보조 설명을 가독성 있는 13/20으로 통일했다. 색상은 `tokens.ts`의 primary/secondary/success 의미를 따른다.

## 배치와 화면 크기

- 기준 미리보기는 402×874. 가로 360px에서도 내용 누락 없이 스크롤 가능해야 한다.
- 공통 좌우 여백 20, 카드 내부 16, 카드 사이 12, 주요 섹션 사이 24.
- eyebrow 다음 제목 8, 제목 다음 설명 8. 설명의 줄 수가 늘면 다음 영역이 내려간다.
- 뒤로가기 있는/없는 eyebrow 시작점은 `PageEyebrow`의 기존 규칙 유지. 보험 선택의 헤더 바로 아래 제목은 별도 헤더형 변형이다.
- 제목·본문은 공통 흐름에 배치한다. 절대좌표로 본문을 고정하거나 강제 높이로 긴 글을 잘라내지 않는다.
- CTA는 `AppScreen.fixedFooter` 사용. 위치는 `footerPlacement="plain"`(기본값, safe area 위 48px)과 `footerPlacement="tabbed"`(탭바 위 12px) 두 가지다. 탭바가 있는 화면은 후자를 명시한다. 시작 화면이나 신규 화면에 별도 bottom/margin/padding 오프셋을 추가하지 않는다. 본문은 실제 footer 높이만큼 스크롤 여백을 확보한다.
- 탭 pill은 하단 safe area에 더해 36px 띄워 비탭 CTA의 하단선보다 조금 낮은 위치에 둔다. 선택된 탭의 글씨·아이콘·배경 상태는 함께 바뀐다.
- 웹 휴대폰 프레임은 검수용이다. iOS/Android 레이아웃에 넣지 않는다.

## 상호작용과 접근성

- 화면마다 주 CTA 하나. 비활성·눌림·처리 중 동작을 정의하고 중복 상태 전이를 막는다.
- 입력 화면은 현재 단계의 필수 조건이 충족되면 CTA를 활성화한다. 오류는 관련 입력 아래 같은 안내 영역에 표시하고 다시 편집하면 이전 오류를 지운다. 키보드의 다음/완료는 다음 입력이나 단계 검증으로 이어지고 화면 전환 시 키보드를 닫는다.
- 보험 선택은 박스 전체를 누르고 테두리로 표시한다. 접근성 선택 상태도 제공한다.
- 체크와 동의 상세 보기를 분리한다. 상세를 닫아도 체크 유지, 시트를 닫으면 임시 선택 초기화.
- 뒤로가기·홈 복귀·작업 종료는 별개다. 진행 중 화면을 나갔다가 돌아와도 작업을 새로 시작하지 않는다.
- 터치 영역은 hitSlop 포함 최소 44. 글자 확대와 모션 줄이기를 지원한다. 긴 데이터는 줄바꿈하며 양쪽 값이 겹치지 않는다.
- 초기화는 결과 상세 화면에서만 파란 홈 복귀 CTA 바로 위 회색 보조 버튼으로 제공한다(2026-09-22 사용자 지정). 누르면 저장된 로컬 데모 상태를 초기값으로 바꾸고 온보딩으로 돌아간다.

## 주행과 데이터

- 시작 시각을 로컬 상태에 저장하고 현재 시각 차이로 HH:MM:SS를 계산한다. interval 횟수를 시간으로 누적하지 않는다.
- 화면 복귀·새로고침 후 시작 시각을 재사용한다. 종료 시각은 한 번만 저장하며 결과 화면에서 같은 시간을 표시한다.
- 기존 저장 상태에 시각이 없다면 재개 시점부터 센다. 과거에 측정하지 않은 시간을 만들어내지 않는다.
- 바깥 원만 회전하고 중앙 글씨는 정지한다. 백그라운드와 모션 줄이기 설정에서는 회전을 멈춘다.
- 첫 운행 전 점수는 계산 기준 100점을 노출하지 않고 `--점`으로 표시한다. 첫 결과는 92점 자체를 첫 점수로 소개하고 `-8점` 변화로 표현하지 않는다. 이후 결과는 실제 이전 점수와 비교한다.
- 실제 경과 시간과 고정된 모의 운행 결과는 별개다. 고정된 12.4km를 실시간 거리처럼 표시하지 않는다. 거리·점수는 기존 데모 fixture가 기준이며 홈·결과는 같은 상태를 읽는다.
- 로컬 모의 상태를 실제 보험사 제출·Midnight 검증으로 표현하지 않는다.

## 자산과 변경 검수

첫 화면은 사용자 제공 3D V 심볼 이미지를 사용한다. 임의 D 문자로 대체하지 않는다. 현재 자산은 사용자 스크린샷이므로 배경·해상도 한계가 있으며 추후 투명 원본으로 교체 가능하다.

수정 시 역할별 토큰을 우선 수정하고 화면별 fontSize/lineHeight를 추가하지 않는다. 기호 형태 아이콘은 타이포 예외다. 주요 화면의 줄바꿈·CTA 간섭·스크롤과 타이머의 시작/복귀/종료를 확인한다. 브라우저 검증과 실제 기기 검증을 구분해 기록한다.
