# 웹 화면별 1:1 캡처 비교 — 수정 목록만

2026-09-22 비교 기록. 2026-09-23에 아래 공통 보정 후보를 제품 코드와 테스트에 반영했다.

Figma에서 내려받은 01–20 SVG의 렌더링과 현재 실제 App을 브라우저에서 캡처한 20장을 비교했다. 대시보드 1512×928, 평가 요청 1512×857로 원본과 동일한 크기다. 완료 상태는 동일 App에 메모리 fixture를 주입해 재현했다. 브라우저와 SVG 렌더러의 안티앨리어싱 차이가 있어 픽셀 차이율을 정확도 점수로 사용하지 않았다.

비교 캡처는 저장소 크기를 늘리지 않도록 로컬 `artifacts/`에만 보관하고 Git에는 포함하지 않는다.

## 반영한 수정 후보

1. **전 화면 글꼴:** Pretendard를 우선 글꼴로 고정하고 숫자 역할에 tabular 숫자를 적용했다.
2. **전 화면 탭:** 확정 글꼴 기준으로 탭 간격을 재조정했다.
3. **전 화면 아이콘:** 대체 문자를 Lucide 선형 아이콘으로 교체하고 검증·비공개 안내 선 굵기를 통일했다.
4. **정보/평가 결과:** 2×2 조건 표의 외곽선 색과 모서리 반경을 낮췄다.
5. **검증/이력:** 검증 카드의 수직 여백과 제목 행간, 타임라인 점·연결선의 크기와 농도를 보정했다.
6. **완료 화면:** 완료 문구 기준선을 올리고 적용·미적용 문구와 상태 배지를 구분했다.
7. **12번 완료 이력:** 제출·검증·대기 전환·최종 승인 순서의 네 단계 이력을 보충했다.

## 단순 디자인 수정과 구분할 차이

- 김서연 7% → 10%: 기존 합의 규칙을 따른 차이. 원본을 맞추려면 규칙부터 변경해야 하므로 임의 수정하지 않음.
- 08·19 성공 카드, 09·20 성공 이력은 원본의 실패 상태와 모순. 구현의 실패 표시 유지.
- 04·05 및 10–12 완료 후 원본 ‘승인 대기’, 활성 승인 버튼은 복제하지 않음. 완료 상태 유지.
- 04·05·16·17의 ‘결정 변경’ 미제공과 처리 후 KPI 갱신은 현재 단일 결정 정책에 따른 차이.
- 실패 시 반려/미적용까지 차단된 것은 원본과 다름. 허용 여부는 업무 정책 판단 사항이며 이번에는 변경하지 않음.
- 실제 가입자 앱 전달은 미구현이므로 원본의 전달 완료 의미 문구를 그대로 사용하지 않음.
- 6개 사이드 메뉴 중 추가 4개는 안내창만 있음. 별도 업무 화면 완성을 의미하지 않음.
