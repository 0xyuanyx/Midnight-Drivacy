## 원인과 수정

이전 구현은 원본 측정 대신 제안 토큰과 다른 정보 모델을 사용했다. 로고 앞 심벌, 멀리 떨어진 INSURER CONSOLE, 페이지 eyebrow, 큰 검색창, KPI 종류, 긴 목록 행, 계약 필드 상세, 추가 하단 카드가 원본과 달랐다.

원본 01–20을 SVG로 내려받아 직접 렌더링하고 확인했다. 01은 텍스트·좌표를 추출했다. 이제 워드마크 아래 INSURER, 6개 메뉴, 보험사 계정 영역, 4개 KPI, 안내 배너, 조밀한 표, 점수/할인율과 2×2 조건 표, 비공개 안내, 증명 표, 세 줄 타임라인을 공통 컴포넌트로 사용한다. 원본 조회를 위해 추가했던 Figma 내보내기 설정은 되돌렸다.

브라우저에서 두 업무 × 가입자 4명 × 탭 3개, 총 24개 조합을 순회했다. 모든 상세 높이 610px, 대시보드 y285 / 평가 y215, 가로 넘침 없음, 실패 승인 비활성, 완료 재승인 없음이 확인됐다. 별도 localhost 저장소에서 승인·반려·할인 적용·미적용을 실행하고 새로고침 후 반려 상태 복원을 확인했다. 사용자 미리보기의 127.0.0.1 저장소는 이 QA 결정으로 변경하지 않았다.

1512/1440/1280/1024/768/390px 실제 innerWidth를 확인하고 패널·버튼의 화면 내 배치 및 문서 가로 넘침 없음을 검수했다. 초기 다중 탭 viewport 호출이 적용되지 않은 측정은 증거에서 제외하고 단일 탭으로 재검수했다.

## 의도적 차이

1. Figma 김서연의 7%는 합의된 80점 이상 10%·90점 이상 12% 규칙과 충돌해 10%를 유지한다. 웹 예시 거리는 524.8km이며 모바일의 550km와 독립적이다.
2. 실패 프레임 08/19의 내부 성공 문구를 실패로 고쳤다. 실패 사유가 확인되지 않은 다른 해시 항목까지 임의로 실패 처리하지 않는다.
3. 처리 완료 프레임 10–12의 승인 대기·활성 승인과 결정 변경은 복제하지 않는다. 완료 배지와 결과를 표시하고 재결정을 막는다.
4. 결정 후 KPI·목록·이력은 함께 갱신한다. 원본의 고정 통계는 기존 집계 예시+현재 세션의 결정으로 표현한다. 목록에 표시되지 않은 과거 집계가 포함되는 독립 fixture다.
5. 원본에 없는 로딩·실패·필터 확장·저장 확인·키보드 탭 이동을 제공한다. 실제 가입자 앱 전달을 주장하지 않고 결과 저장 문구를 쓴다.
6. 데모 경계는 도움말과 결정 확인에 둔다. 실제 증명·보험사 API 연동은 수행하지 않는다. 추가 4개 메뉴는 범위 안내이며 새 업무 화면 완성이 아니다.
