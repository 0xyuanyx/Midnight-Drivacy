# 추가 메뉴 검토 — 2026-09-24

## 유지한 결정

5개 메뉴, 특약 관리 안의 규칙 변경, 문서 추출→내용 수정→초안 안내, 검증 이력→평가 요청 상세, 읽기 전용 연동 상태를 유지한다.

## 수정

- 목록 이름 12/15, 보조 9/11, 내부 카드 반경 12px, 하단 행동 영역 최소 74px로 통일.
- 특약 상세·검증 이력의 하단 행동 영역을 패널 하단에 배치.
- 특약 탭에 방향키·Home/End·선택 탭 포커스·패널 이름 연결 적용.
- 규칙 변경 단계는 탭이 아닌 선택 버튼 그룹으로 명시.
- 문서 확인 중 하단에서 다시 업로드 단계로 돌아가던 중복 CTA를 현재 조건 보기로 변경. 탭 복귀 시 편집 상태 유지.
- 검증 정보 없음·규칙 확인 전은 성공색 대신 중립색 사용.
- 연동 상태는 브리지 설정 여부를 표시하며 실제 응답 성공으로 단정하지 않음.

## 남은 기능/흐름 차이

- 수정된 약관 내용으로 Rule Draft API를 호출하는 토큰 주입형 경계와 결과·근거 검토 및 수기 입력 폼을 추가했다. 기본 실행에는 로그인 토큰과 실제 특약 ID가 없어 호출하지 않는다. 초안 저장·승인·등록은 여전히 연결되지 않았다.
- 특약 탭·문서 편집 내용과 검증 이력 검색은 새로고침 후 복원되지 않는다. 영속 초안 저장은 별도 연결이 필요하다.
- 로컬 연동 평가 요청의 결정 버튼은 기존 규칙의 확인 단계 없이 바로 저장한다. 이번 세 메뉴 외의 후속 수정 대상이다.
- 연동 상태는 실제 헬스체크가 아니며 실제 Backend/보험사/ZK 연결 여부를 자동 검사하지 않는다.
- 서버 인증·권한·영속 저장과 실제 증명 연결은 이번 UI 검증 범위 밖이다.
