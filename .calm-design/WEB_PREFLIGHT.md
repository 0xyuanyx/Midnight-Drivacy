# 보험사 웹 Pre-Flight

## 시각·구조 검수

- [x] 원본 Arial 계열 타이포와 한국어 fallback을 적용하고 Pretendard도 번들한다.
- [x] 검정·회색 본문은 의미별 공통 타이포 토큰을 사용한다.
- [x] DriVacy의 `Vacy`와 업무 강조색은 원본 파란색 계열을 따른다.
- [x] 순수 검정 배경, 보라색 그라데이션, 장식성 대형 히어로를 사용하지 않는다.
- [x] Sidebar, KPI, 목록, 상세, 탭, 행동 영역의 정렬 규칙을 두 업무 화면에서 공유한다.
- [x] 상태색은 텍스트 라벨과 함께 표시해 색만으로 의미를 전달하지 않는다.
- [x] 500km 승인 기준과 웹 원본의 524.8km 예시를 구분한다. 모바일 예시는 550km다.
- [x] 로딩, 빈 결과, 로드 실패, 저장 중, 저장 실패 상태를 구분한다.
- [x] hover, focus-visible, active, disabled 상태가 정의되어 있다.
- [x] 확인 모달은 진입 포커스, 포커스 순환, Escape 닫기, 원래 버튼 복귀를 제공한다.
- [x] 실제 innerWidth 1512/1440/1280/1024/768/390에서 핵심 콘텐츠 접근과 가로 넘침을 확인했다.
- [x] 긴 한국어 문구는 `word-break: keep-all` 기준으로 읽히게 한다.
- [x] 브라우저 새로고침 후 결정 상태가 fixture 저장소에서 복원된다.
- [x] 실제 연동이 아니라는 경계를 화면과 문서에 명시한다.

## 후속 검수 결과

- [x] 탭 좌우 방향키·Home/End·roving tabindex 구현 및 테스트 통과.
- [x] 원본에 없는 상세 닫기를 제거하고 필터·정렬·도움말·알림·계정 동작을 연결했다.
- [x] 39%/61%+gap 대신 minmax(0,2fr)/minmax(0,3fr)로 넘침 원인을 제거했다.
- [x] 원본 20개와 구현 상태 조합 24개를 확인하고 주요 원본 좌표 1px 이내를 검증했다.
- [ ] 추가 4개 메뉴의 독립 업무 화면은 미구현이며 현 범위 안내를 제공한다.
