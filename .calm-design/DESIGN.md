# Design System: Drivacy 가입자 모바일

> Generated by calm-design · LANGUAGE: ko · VARIANCE: 3 · MOTION: 2 · DENSITY: 5 · Mode: B

## 0. Brand Philosophy

Drivacy는 보험에 필요한 결과와 보호되는 원본의 차이를 사용자가 즉시 이해하게 한다. 핵심 가치는 최소 공개, 명확한 동의, 차분한 신뢰다. 한 화면에는 하나의 주 CTA만 두고 개인정보 관련 문구는 추상적인 홍보 표현보다 구체적인 데이터 항목을 우선한다.

## 1. Visual Theme & Atmosphere

수정 Figma 모바일 프레임을 기준으로 옅은 회색 canvas, 흰 surface, 단일 파란 accent, 작은 초록 상태 pill을 사용한다. 정보는 큰 제목, 한 개의 핵심 카드, 보조 카드 순으로 읽히게 한다. 장식보다 여백과 정렬로 화면의 위계를 만든다.

## 2. Color Palette & Roles

| 이름 | Hex | 역할 |
|---|---|---|
| Canvas | `#F2F2F7` | 앱 배경 |
| Surface | `#FFFFFF` | 카드와 시트 |
| Ink | `#1E1E1E` | 제목과 핵심 값 |
| Mute | `#66758C` | 설명과 보조 문구 |
| Accent | `#2E6EED` | CTA·체크·선택 테두리 |
| Success | `#2E9D65` | 충족·완료 상태 |
| Privacy | `#EAF2FF` | 최소 공개 안내 |

## 3. Typography Rules

Pretendard Regular/SemiBold/Bold 파일을 앱에 번들한다. `src/theme/typography.ts`의 역할별 스타일이 실행 기준이며 화면 제목 24/34, 카드 제목 16/24, 본문 16/25, 보조 설명 13/20을 공유한다. 상세 규격·예외는 `docs/MOBILE_APP_RULES.md`를 따른다. 사용자 승인 앱 개선이 Figma보다 우선한다.

## 4. Components

- Primary CTA: 54px 높이의 full-width blue pill. 탭 없는 화면은 safe area 위 공통 고정 슬롯, 탭 화면은 pill tab 위 공통 고정 슬롯에 둔다.
- Floating tab: 홈·주행·서류 세 항목, 흰 pill과 회색 선택 배경을 사용하고 화면 하단에서 12px 띄운다.
- Information card: 흰 배경, 16px radius, 그림자 없이 canvas 대비로 분리한다. 선택 카드만 1px 파란 테두리를 사용한다.
- Consent row: 왼쪽 원형 체크, 한 줄 필수 제목, 오른쪽 chevron. chevron은 상세 보기, 체크 영역은 동의 상태 변경으로 역할을 분리한다.
- Disclosure view: 제목, 목적, 처리 정보, 이용 범위/제외 정보의 짧은 섹션과 확인 CTA를 사용한다.
- Eyebrow: 뒤로가기 헤더가 있는 화면과 없는 화면의 두 고정 시작 위치를 사용하며 화면별 임의 margin을 두지 않는다.
- Wordmark: `DriVacy` 표기에서 대문자 `V`만 Accent blue로 표시한다.

## 5. Layout Principles

402×874를 기준 프레임으로 사용한다. 화면 가로 여백은 20px, 카드 간격은 10–13px, 주요 영역 간격은 22–30px다. CTA는 내용 길이에 따라 떠다니지 않으며 같은 내비게이션 조건의 화면끼리 동일한 하단 위치를 공유한다. 스크롤 본문은 CTA 아래로 가려지지 않도록 82px의 하단 여유를 갖는다.

## 6. Web Preview

web은 별도 웹 제품이 아니라 React Native 앱 검수 표면이다. 넓은 브라우저에서는 검은 stage 중앙의 402×874 아이폰형 프레임과 Dynamic Island를 표시한다. 이 프레임은 web 전용이며 iOS·Android 빌드에는 포함하지 않는다. 동의 overlay도 프레임 경계 안에 머문다.

## 7. Motion & Interaction

상태 변화는 즉시 반영한다. 주행 중에는 바깥 원만 회전하며 중앙 타이머는 저장한 시작 시각 기준으로 흐른다. 백그라운드·모션 줄이기에서 회전을 중단한다. 두 필수 동의가 모두 선택돼야 진행 CTA가 활성화된다. 상세 보기를 닫으면 체크 상태는 유지하며 시트 전체를 닫으면 임시 선택을 초기화한다.

## 8. Anti-Patterns

- 초기화는 결과 상세의 홈 복귀 CTA 위에만 회색 보조 버튼으로 둔다(사용자 최신 지정).
- 보험 선택에 별도의 시각적 radio dot을 노출하지 않는다.
- 실제 보험사 제출, 실제 Midnight 증명 또는 체인 확인이 완료된 것처럼 표현하지 않는다.
- 카드 중첩, 보라색 gradient, 과도한 그림자와 장식 아이콘을 추가하지 않는다.
- web의 아이폰 프레임을 실제 앱 UI 자산으로 포함하지 않는다.

# Design System: Drivacy 보험사 운영 웹

> Generated by calm-design · LANGUAGE: ko · VARIANCE: 2 · MOTION: 2 · DENSITY: 7 · Mode: B

## 0. Brand Philosophy

보험사 담당자가 운전 원본을 보지 않고도 증명 결과와 업무 결정을 분리해 검토하도록 돕는다. `증명 유효`, `조건 충족`, `업무 처리 완료`는 서로 다른 상태로 표현한다.

## 1. Visual Theme & Atmosphere

짙은 남색 사이드바와 옅은 회색 업무 canvas, 흰색 패널로 안정적인 운영 도구의 인상을 만든다. 장식보다 목록-상세 관계, 상태, 다음 행동이 먼저 읽혀야 한다.

## 2. Color Palette & Roles

2026-09-22 Figma 정밀 대조로 웹 값을 교체했다. Canvas `#F3F6FA`, Surface `#FFFFFF`, Sidebar `#14213D`, Ink `#182235`, Secondary `#68758A`, Border `#E3E8F0`, Accent `#2F6DF6`를 사용한다. 성공·주의·오류는 색과 텍스트를 함께 쓴다.

## 3. Typography Rules

웹은 원본 Arial 계열과 한국어 시스템 글꼴을 사용하고 Pretendard Regular/Bold를 fallback으로 번들한다. 페이지 제목 24/29, 상세 제목 17/20, 섹션 제목 15/20, 목록 이름 12/15, 버튼 10/14, 보조·상세 eyebrow 9–10px을 역할별로 고정한다. 모바일 타이포와 별도다.

## 4. Components

AppShell, PageHeader, SummaryCard, RequestList, RequestDetail, DetailTabs, ResultDetail, ProofDetail, HistoryList, StatusBadge, ActionBar, AsyncState를 공통 계약으로 사용한다. 대시보드와 평가 요청은 이 컴포넌트를 조립하고 별도 복제하지 않는다.

## 5. Layout Principles

1512px 너비에서 220px 사이드바, 본문 좌우 32px·상단 22px, 섹션 간격 16px을 유지한다. 목록과 상세는 gap을 제외한 너비를 2:3으로 배분하고 960px 이하에서 단일 열로 전환한다. 상세 패널 높이는 610px을 기준으로 한다. 실측값은 docs/WEB_FIGMA_AUDIT.md에 기록한다.

## 6. Information Architecture

사이드바는 원본의 6개 메뉴를 모두 표시한다. 실제 업무 화면은 대시보드와 평가 요청이며 나머지 4개는 현 범위 안내를 제공한다. 선택 요청 ID, 상세 탭, 검색과 필터는 URL에 남긴다. 로고 앞 심벌과 CONSOLE은 없으며 INSURER는 워드마크 바로 아래 둔다.

## 7. Motion & Interaction

hover·focus·pressed·disabled·busy 상태를 짧고 조용하게 표현한다. 승인·반려·할인 적용처럼 저장되는 결정은 대상과 결과를 확인하는 한 번의 확인 단계를 거친다. 모션 줄이기에서는 이동 효과를 제거한다.

## 8. Anti-Patterns

- 20개 Figma 상태를 20개 페이지로 복제하지 않는다.
- 검증 성공을 보험 업무 승인으로 표현하지 않는다.
- 원본 위치·경로·정확한 주행 시각을 노출하지 않는다.
- mock을 실제 API, 실제 Midnight 증명 또는 체인 연동으로 표현하지 않는다.
- 동일 크기 3열 카드, 보라색 gradient, 과도한 그림자와 장식 아이콘을 사용하지 않는다.
